## 중요한 설계 결정과 책임 경계

- 두 조회는 기존 `QueryGateway`와 로그인 session을 사용하며 요청·결과는 thread-safe queue를 지난다.
- HTTP redirect를 따르지 않고 기존 timeout·status·Content-Type 제한을 그대로 적용한다.
- `available=false`는 `아직 측정 전`, nullable RTT는 `표본 없음`으로 표시한다.
- metrics 생성 시각과 Spark progress 시각을 별도 라벨로 유지한다.
- Kafka lag가 일부 partition에서 확인되지 않으면 `일부 위치 미확인`을 표시한다.
- 카드는 저장 결과를 읽을 뿐 부하 측정, Kafka 연결, Spark 작업이나 게임 state 변경을 시작하지 않는다.
- 기존 광고 slot, 게임 상태·WS·이동·채집·수련·이력 패널은 유지한다.
