## 구현 결과

- root의 집중 구현을 `client/application`, `model`, `contracts`, `network`, `ui`로 이동했다.
- `NetworkWorker`는 thread·loop·queue·dispatch·종료만 맡는다.
- HTTP, 인증 session, WebSocket play, 조회 gateway를 분리했다.
- HTTP와 WS는 worker의 같은 `ClientSession`을 사용한다.
- renderer는 Controller가 만든 frozen `ScreenModel`만 읽는다.
- draw와 hit test는 같은 frame의 `Layout`을 사용한다.
- world는 projection, terrain, markers, actors, nameplates, scene으로 분리했다.
- 기존 root 구현과 내부 구현에 결합된 root 테스트는 제거했다.

## 행동 통계 조건 확인

- `QueryGateway`가 버튼 request를 받은 경우에만 `GET /api/analytics/actions/`를 호출한다.
- redirect를 따르지 않고 timeout, status, Content-Type, 64KiB 제한을 적용한다.
- 302/401/403과 HTML body는 JSON parser에 전달하지 않는다.
- queue event에는 path, status, 허용 JSON, 고정 문구와 상관관계만 포함한다.
- `available=false`는 `행동 집계가 아직 없습니다`이며 0건으로 바꾸지 않는다.
- true 패널에 source_topic, source_kind, generated_at, 고유 행동 수, 세 행동 카드, 방별 행동 수, 원본 전달 행 수, 고정 snapshot 안내가 있다.
- 조회 버튼은 GET만 요청하며 Spark 실행·Kafka 연결 코드는 없다.
- 광고 slot과 기존 CC0 asset 경로를 유지했다.
- 모델 추천, 자동 사냥, 자동 반복 수련을 추가하지 않았다.
